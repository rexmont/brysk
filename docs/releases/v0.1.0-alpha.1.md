Initial **alpha** release of **Brysk**, a Rust file manager extensively reworked and extended for macOS. Early software: expect rough edges and report issues.

- Native macOS integration, Command shortcuts, menus, dialogs, sharing and permission onboarding.
- Tabs, split panes, multiple views, Finder-style file operations and drag previews.
- DirectLook previews for images, video, PDFs, text and archives, with sharper image loading.
- Fast name search, asynchronous listing and thumbnails, and memory/performance improvements.
- Optional Finder Dock-click replacement, plus macOS folder, icon and navigation fixes.
- Signed in-app updates, separate Close/Quit controls, and HyperSearch shortcut/focus fixes.

**Download:** Developer ID-signed and notarized universal DMG for Apple silicon and Intel. Requires macOS 13 or later.

Based on [rustyfiles](https://github.com/gelenmedya/rustyfiles) by Özer Güzel, with extensive macOS-specific changes. See the [README](https://github.com/rexmont/brysk#readme) for features and known limits.
